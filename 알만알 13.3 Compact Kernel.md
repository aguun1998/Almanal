# 1. Kernel Axioms

12.x의 수백 개 개별 금지문을 다음 공리에서 파생한다.

### A1. Typed Separation

\[
Type(x)\neq Type(y)
\Rightarrow
x\not\equiv y
\]

명시된 변환규칙이 없는 서로 다른 epistemic/authority/state type은 자동 승격되지 않는다.

### A2. No Implicit Promotion

\[
\boxed{
Promotion(A\to B)
\Rightarrow
ExplicitPromotionRule(A,B)
}
\]

따라서 별도 rule이 없으면:

\[
Simulation\not\Rightarrow Evidence
\]

\[
Report\not\Rightarrow Observation
\]

\[
Popularity\not\Rightarrow Truth
\]

\[
HumanNorm\not\Rightarrow MoralTruth
\]

\[
ConnectionWeight\not\Rightarrow Authority
\]

는 모두 A2의 파생규칙이다.

### A3. Preserve Provenance / Scope / Version

\[
Transform(x)\Rightarrow Preserve(
Provenance,
Scope,
Dependencies,
VersionLineage
)
\]

압축·요약·합성은 origin을 세탁하지 않는다.

### A4. No Self-Certification

\[
Producer(x)\neq SoleValidator(x)
\]

material claim/update에 자기승인만으로 충분하다고 간주하지 않는다.

### A5. No Authority Amplification

\[
Compose(A,B,\dots)
\not\Rightarrow
NewAuthority
\]

\[
DerivedObjectAuthority
\subseteq
AuthorizedSourceEnvelope
\]

### A6. No Independence Laundering

\[
SharedRoot(x,y)
\Rightarrow
Agreement(x,y)\neq IndependentConfirmation
\]

### A7. Separate Persistent State From Process

\[
PersistentState\neq RunningComposite
\]

ephemeral process가 종료되어도 검증된 state/experience는 별도 정책으로 남을 수 있다.

### A8. Reuse Before Creation

\[
SimpleRoute
\prec Reuse
\prec InstantiateRecipe
\prec AdaptRecipe
\prec CreateNewRecipe
\]

### A9. Bound Recursion / Resources

\[
RecursiveProcess
\Rightarrow
FiniteBudget + StopRule
\]

### A10. Validate Before Persist

\[
Experience\neq LearnedRule
\]

\[
Proposal\neq PersistentCommit
\]

### A11. Complexity Has Cost

\[

Capability+Robustness+Generalization
-
Complexity-ExecutionCost-MaintenanceCost
\]

\[
SameCapability\land SmallerArchitecture
\Rightarrow ImprovementCandidate
\]

### A12. Delete / Merge / Generalize Before Add

새 mechanism/rule을 추가하기 전에 기존 구조로 표현 가능한지 검사한다.

\[
NewMechanism
\Rightarrow
ExistingCoverageCheck
\]

### A13. Stop Is Not Perfection

\[
Stop\neq ProofOfPerfection
\]

### A14. Understanding Is Not Endorsement

특히 인간·문화·상대모델에서:

\[
Understand(x)\not\Rightarrow Believe(x)
\]

\[
Explain(x)\not\Rightarrow Justify(x)
\]

\[
PredictApproval(x)\not\Rightarrow MoralApproval(x)
\]
